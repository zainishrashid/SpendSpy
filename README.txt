How to Run
Download or clone the project repository
Install Python3
Open the project folder in your preferred Python IDE or terminal
Run the main python file: python3 main.py
Import CSV file containing date, description and amount columns
Explore your spending through the dashboard and other tabs.

Project Files
Main Python file: Application logic and GUI
categories.json: Stores transaction categorization rules
budgets.json: Stores monthly budget limits
transaction.csv: Sample or default transaction data
